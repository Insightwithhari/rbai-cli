# Getting help

1. **Run `rbai doctor`.** It checks your installation, your settings, the network and your sign-in, and says how to
   fix what fails.
2. **Read the documentation.** The [user guide](https://rbai.thedreamlabinnovations.com/docs/cli-access) covers
   installing, signing in, the chat, working in a folder and troubleshooting. Every command is in
   [docs/reference.md](docs/reference.md), and `rbai <command> --help` shows the same in your terminal.
3. **Ask.** Start a thread in [Discussions](https://github.com/Insightwithhari/rbai-cli/discussions), or open a
   [question](https://github.com/Insightwithhari/rbai-cli/issues/new/choose).
4. **Something broken?** Open a [bug report](https://github.com/Insightwithhari/rbai-cli/issues/new/choose).

Questions about your account, your plan or a payment don't belong in public. Email
[hari@thedreamlabinnovations.com](mailto:hari@thedreamlabinnovations.com) instead, or use the
[contact page](https://rbai.thedreamlabinnovations.com/contact).

For a security problem, follow [SECURITY.md](SECURITY.md).

Never post an API key, a sign-in code or a token anywhere on GitHub. If you did by mistake, revoke the key in RBAi
under **Settings → API keys**.
