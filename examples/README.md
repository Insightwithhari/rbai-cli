# Examples

Each example here shows a question for the RBAi CLI, the tools RBAi called to answer it, and the answer exactly as
RBAi wrote it. Where an answer is shortened, the example says so.

RBAi looks things up live, so the same question asked on another day can get a different answer. AI answers can
also contain mistakes, so check an important result against the records the answer links to.

| Example | What it shows |
| --- | --- |
| [A variant: TP53 R175H](variant-tp53-r175h.md) | A ClinVar lookup and a literature search behind one answer |
| [A list of drugs: PD-L1 inhibitors](drug-list-pd-l1.md) | Literature and web searches, with sources for each group |
| [A predicted structure: KRAS in AlphaFold](alphafold-kras-confidence.md) | AlphaFold's own confidence numbers for a protein |
| [A file on your computer: counts.csv](local-counts-csv.md) | `--local`, where RBAi reads a file in your folder |
| [A reagent: an anti-GPX4 antibody](connect-gpx4-antibody.md) | Connect, which looks for materials, services and labs |

Have you made something useful with rbai? Real examples are welcome. [CONTRIBUTING.md](../CONTRIBUTING.md) says how
to send one.
