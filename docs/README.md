# Documentation

| File | What it is |
| --- | --- |
| [reference.md](reference.md) | Every command, flag, default, exit code and environment variable. It is the same text as `rbai help reference`. |
| [agents.md](agents.md) | The guide for AI agents and scripts: signing in, JSON output, exit codes, `rbai ask` and its events, credits, safety and recipes. It is the same text as `rbai help agents`. |
| [agent-kit.md](agent-kit.md) | What each file of the agent kit is for, and how to install it in each AI tool. |

The user guide, with installing, signing in, the chat, working in a folder and troubleshooting, is on the website:
[rbai.thedreamlabinnovations.com/docs/cli-access](https://rbai.thedreamlabinnovations.com/docs/cli-access).

The three files above are copied here from RBAi's own sources with every release, so they describe the newest
version. To report a mistake in one of them, open a
[documentation issue](https://github.com/Insightwithhari/rbai-cli/issues/new/choose).
