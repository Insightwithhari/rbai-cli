# RBAi agent kit (rbai 1.7.0)

RBAi is a research assistant for the life sciences (https://rbai.thedreamlabinnovations.com). This kit teaches
AI agents and IDEs to use its command line, `rbai`, and its MCP server: Claude Code, Kiro, Gemini CLI, Codex,
Cursor, VS Code with GitHub Copilot, and any client that reads Agent Skills or the MCP Registry.

It holds only instructions and configuration: no program code and no keys. The CLI itself comes from its
installer (cli.thedreamlabinnovations.com) or npm.

## First, on every computer

```sh
curl -fsSL https://cli.thedreamlabinnovations.com/install.sh | sh # macOS and Linux (no Node.js needed)
irm https://cli.thedreamlabinnovations.com/install.ps1 | iex      # Windows PowerShell
npm install -g rbai-cli                                           # or with Node.js 22 or later
rbai auth login                                                   # then, in a new terminal: approve this computer in the browser
```

Every MCP entry below starts `rbai mcp serve`, which uses that sign-in. No key goes into an IDE's settings.

## Install it in your client

| Client | How |
| --- | --- |
| Claude Code | `/plugin marketplace add <owner>/<this repository>`, then `/plugin install rbai@thedreamlabinnovations` (the skill and the MCP server) |
| Kiro | Powers panel → Add Custom Power → Import power from GitHub → this repository's URL (plugin.json, mcp.json and skills/: a power in the Agent Plugins format); or `rbai agent-skill --client kiro --write` for the skill alone |
| Gemini CLI | `gemini extensions install https://github.com/<owner>/<this repository>` (gemini-extension.json, GEMINI.md, skills/) |
| Codex | `rbai agent-skill --client codex --write` (the skill in ~/.agents/skills), and the block in codex/config.toml in ~/.codex/config.toml; AGENTS.md has the short rules for a project |
| Cursor | `rbai agent-skill --client cursor --write` (the skill), the MCP server with the install link below, and optionally cursor/rules/rbai.mdc copied to .cursor/rules/ |
| VS Code (GitHub Copilot) | `rbai agent-skill --client vscode --write` (the skill in ~/.copilot/skills), the MCP server with the install link below, and optionally vscode/rbai.instructions.md copied to .github/instructions/ |
| Any Agent Skills client | Copy skills/rbai/ into the client's skills folder |
| MCP Registry clients | Search the registry for `com.thedreamlabinnovations/rbai` |

`rbai agent-skill --client <claude-code|kiro|cursor|codex|vscode|gemini> --write` installs the same files from the
CLI you have, without this repository; `--print` shows them first. After updating rbai, run it again with `--force`.

On Windows with the npm package, if a client cannot start `rbai` (some start commands without a shell, and npm's
`rbai.cmd` needs one), print a configuration with the full path instead: `rbai mcp config --client <name>`. The
installer's `rbai.exe` starts without a shell.
